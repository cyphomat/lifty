Setlist · setup

1 · GitHub — deine Daten

Damit liest und schreibt die App dein eigenes privates Datenrepo.

  1. Leg unter diesem Namen ein privates Repo an — mindestens mit einer config.json
  2. Klick oben rechts auf dein Profilbild → Settings (deine persönlichen Kontoeinstellungen, nicht die Settings des Repos) → Developer settings → Personal access tokens → Fine-grained tokens
  3. Generate new token, Zugriff auf nur dieses Repo
  4. Permissions: Contents → Read and write. Sonst nichts.

2 · intervals.icu OPTIONAL

Liefert deine gefahrenen Radeinheiten und — falls dort gepflegt — deinen Gewichtsverlauf.

Beide Schlüssel bleiben im Speicher dieses Browsers. Sie werden nie ins Repo geschrieben und tauchen in keinem Commit auf.
